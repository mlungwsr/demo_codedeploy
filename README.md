# AWS CodeDeploy Demo Website

This is a futuristic dark-themed single-page website showcasing AWS CodeDeploy. The website is built using only HTML, CSS, and JavaScript.

## Features

- Responsive design that works on mobile and desktop
- Futuristic dark theme with glowing elements and space background
- Interactive animations demonstrating deployment types
- Smooth scrolling navigation
- Animated elements that appear as you scroll

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling including the dark theme and animations
- `script.js` - JavaScript for interactive elements and animations

## How to Use

Simply open the `index.html` file in any modern web browser to view the website.

## Content

The website includes information about:
- What AWS CodeDeploy is
- Key features of CodeDeploy
- Common use cases
- Deployment types (In-place and Blue/Green)
